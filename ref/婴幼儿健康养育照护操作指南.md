# 3岁以下婴幼儿健康养育照护操作指南

> 本指南依据国家卫健委《3岁以下婴幼儿健康养育照护指南（试行）》整理，供养育人参照使用。

---

## 一、核心理念（8条）

1. **重视早期全面发展** — 关注体格、运动、认知、语言、情感及社会适应能力的协同发展。
2. **遵循生长发育规律** — 尊重个体差异，不盲目攀比，定期监测，早发现、早诊断、早干预。
3. **给予恰当积极的回应** — 关注婴幼儿的表情、声音、动作和情绪，及时回应其需求。
4. **培养自主与自我调节** — 在安全前提下鼓励自由探索，建立规律作息，培养自理能力。
5. **注重亲子陪伴和玩耍** — 交流和玩耍是促进早期发展的核心措施。
6. **将学习融入养育全过程** — 利用家庭和社会资源，在日常环节中提供早期学习机会。
7. **创建良好家庭环境** — 温馨和睦的家庭氛围，整洁、安全、有趣的活动空间。
8. **提高自身养育素养** — 养育人主动学习育儿知识，同时关注自身身心健康。

### 2.4 眼病防控

- 定期接受眼保健和视力检查，完成各年龄阶段眼病筛查及"远视储备量"监测。
- 保证充足睡眠、均衡膳食和户外活动，减少持续近距离用眼。
- **2岁以内**：不建议观看或使用电子屏幕。
- **2岁以上**：电子屏幕每天累计不超过1小时，每次不超过20分钟。

> **出现以下症状应及时就诊**：不能追视、对外界反应差；看东西时凑近、眯眼、皱眉、斜眼、歪头；瞳孔区发白、畏光、流泪、眼部发红或有脓性分泌物。

### 2.5 听力障碍预防

- 主动接受耳及听力保健服务，观察儿童对声音的反应和语言发育情况。
- 远离强声或持续噪声环境，避免使用耳机。
- 洗澡或游泳时防止呛水和耳部进水；不要自行清洁外耳道。
- 避免头部、耳部外伤和外耳道异物。
- 患腮腺炎或脑膜炎后，注意观察听力变化。

> **出现以下情形应及时就诊**：耳部及耳周皮肤异常；外耳道有分泌物或异常气味；拍打/抓挠耳部；耳痒/耳痛/耳胀；对声音反应迟钝或语言发育迟缓；头常往一侧歪或对呼唤无回应。

### 2.6 龋病防控

- **第一颗乳牙萌出即开始清洁牙齿**，根据月龄选用纱布、指套牙刷、儿童常规牙刷。
- 使用儿童含氟牙膏，用量为米粒大小。
- 每次进食后喂白开水或清洁口腔。避免餐间摄入含糖饮食，饮水以白水为主。
- **禁止**：将食物嚼碎后喂婴幼儿、与婴幼儿共用餐具。
- **第一次口腔检查**：第一颗乳牙萌出至12月龄之间，之后每3～6个月复查。
- 患龋中/低风险：每年涂氟2次；高风险：每年涂氟4次。
- 乳磨牙深窝沟可行窝沟封闭。

## 三、营养与喂养

### 3.1 母乳喂养

- 出生后尽早皮肤接触、早吸吮、早开奶。
- 6个月内纯母乳喂养，不需加水和其他食物。按需哺乳，每日8～10次以上。
- 促进泌乳：婴儿充分吸吮是最有效方法；母亲心情愉悦、睡眠充足、营养均衡。
- 早产儿：首选母乳喂养，提倡袋鼠式护理。胎龄<34周或出生体重<2000克者，遵医嘱添加母乳强化剂。

### 3.2 微量营养素补充

| 类型 | 维生素D（每天） | 铁剂 |
|------|-----------------|------|
| 足月儿 | 生后数日起 400 IU/天 | 纯母乳喂养者 4～6 月龄酌情补铁 |
| 早产/低出生体重儿 | 生后数日起 800～1000 IU/天，3个月后改为 400 IU/天 | 生后2～4周起 2 mg/(kg·天) |

> 酌情补充钙、维生素A等。补充量均含配方奶及母乳强化剂中的含量。

### 3.3 辅食添加

| 要点 | 说明 |
|------|------|
| **添加时间** | 足月儿6月龄起；早产儿校正胎龄4～6月龄时 |
| **添加原则** | 每次只加一种新食物，由少到多、由一种到多种；从富含铁的泥糊状食物开始，每引入一种适应2～3天 |
| **母乳延续** | 可继续母乳喂养至2岁及以上 |
| **1岁以内** | 不加盐、糖和调味品，保持原味 |
| **1岁以后** | 少盐、少糖 |

**辅食食材7大类**：①谷薯类 ②动物性食物（鱼、禽、肉及内脏）③蛋类 ④奶类和奶制品 ⑤豆类和坚果制品 ⑥富含维生素A的蔬果 ⑦其他蔬果

> 每日辅食种类不少于4种，且至少包括1种动物性食物、1种蔬菜、1种谷薯类。

### 3.4 各月龄辅食添加要点

| 月龄 | 频次（每天） | 每餐量 | 食物质地 |
|------|-------------|--------|----------|
| 6月龄起 | 从1次渐增至2次 | 从尝一尝渐增至2～3小勺 | 泥糊状（稠粥/肉泥/菜泥） |
| 6～9月龄 | 1～2次 | 2～3勺渐增至半碗（250ml碗） | 稠粥/糊糊/捣烂/煮烂的家庭食物 |
| 9～12月龄 | 2～3次 | 半碗 | 细细切碎的家庭食物/手指食物/条状食物 |
| 12～24月龄 | 3次正餐 + 2次加餐 | 3/4碗到1整碗 | 软烂的家庭食物 |

### 3.5 培养饮食习惯

- 1岁以后逐步过渡到独立进食，营造轻松愉快的进食环境，**引导而不强迫**。
- 安排与家人一起就餐，鼓励自主进食。关注饥饱信号，及时回应。
- 不以食物作为奖励和惩罚。
- 进餐时不看电视、手机，每次进餐控制在20分钟左右，最长不超过30分钟。

## 四、交流与玩耍

### 4.1 亲子交流的三种方式

| 方式 | 做法 |
|------|------|
| **身体接触** | 抚摸、拥抱等亲密接触，建立依恋 |
| **肢体语言** | 通过眼神、表情、动作表达关注、喜爱、鼓励和安慰 |
| **语言交流** | 从简单语音→单词→短语→完整语句，讲身边事物，讲故事、读绘本、唱儿歌 |

### 4.2 玩耍运动

- **自由玩耍**：利用室内外各种条件，不拘形式地玩耍，关注好奇心，陪伴、互动、示范。
- **亲子游戏**：念儿歌、躲猫猫、拍手游戏、照镜子、指认身体部位等；提倡父亲参与。鼓励用日常物品或自制玩具。
- **运动锻炼**：提供爬、走、跑、跳（大动作）及抓握、垒高、涂鸦（精细动作）练习机会。
  - 避免久坐超过1小时。
  - 幼儿每天身体活动至少3小时，其中户外活动至少2小时（特殊天气酌情减少）。

### 4.3 各年龄段亲子交流与玩耍要点

| 月龄 | 交流要点 | 玩耍要点 |
|------|----------|----------|
| **0～1月** | 注视新生儿眼睛，温柔说话（尤其哺乳、照护时），让其看脸、听声 | 让其看、听，自由活动四肢；轻柔抚摸和怀抱，亲密皮肤接触更好 |
| **1～3月** | 喂奶或清醒时对其笑，模仿其声音说话交流 | 看、听、接触养育人，自由活动四肢；帮助俯卧、抬头；用红球或圆环移动让其看、触摸 |
| **3～6月** | 经常说话、逗笑，模仿其声音、表情和动作交流 | 多俯卧、抬头，帮其翻身；让其伸手够、抓握玩具；可用不同质地（布、塑料瓶）的玩具 |
| **6～9月** | 对其声音和兴趣给予回应，叫名字观察反应，玩"躲猫猫"，说看到的人或物品 | 练习坐，床上翻滚；提供安全家庭物品让其抓握、传递、敲打（杯子、勺子） |
| **9～12月** | 教认家中物品、人及身体部位；说话、唱歌、结合场景边说边做手势（"欢迎""再见"） | 鼓励爬行、站立和扶走；练习拇食指捏小物品；把玩具放布下玩"藏猫猫" |
| **12～18月** | 问简单问题，回应其说话；用简单指令调动活动，鼓励称呼周围的人，看物品和图片说出名称 | 鼓励独自行走、蹲下和站起，握笔涂画；套叠杯/碗/瓶玩堆叠，物品放进容器再拿出 |
| **18～24月** | 多说话，提问并耐心等待回答，用清晰正确发音回应；边看自然/图画书/物品边交谈 | 多户外活动，扶支撑物上下台阶，扔球、踢球，翻书、拧瓶盖；玩给娃娃喂饭等模仿性游戏 |
| **24～36月** | 一起看图画书、讲故事、说儿歌，讨论图画书内容；教说姓名、性别，认识形状、颜色、用途 | 练习单脚站、双脚蹦跳、踢球；培养自己洗手、吃饭、扣扣子、穿鞋等；与小朋友玩"开火车""骑竹竿"等游戏 |

### 4.4 社交体验

- **家庭活动**：让幼儿参与力所能及的家务（整理衣物、玩具等），通过走亲访友、家庭聚会等活动丰富生活体验。
- **同伴交往**：经常创造与同龄伙伴交流和玩耍的机会，发展关心、分享、合作等亲社会行为，对积极行为及时肯定。关注情绪变化，通过抚摸、拥抱等缓解不良情绪。
- **社区活动**：充分利用公园、儿童活动中心、游乐园等社区资源，接触大自然。

## 五、生活照护

### 5.1 居家环境

- **家庭氛围**：温馨、和谐、愉快。家人保持一致的养育观念。杜绝忽视、虐待和一切形式的家庭暴力。
- **家庭设施**：整洁、舒适。提供适合年龄的餐具、水杯、儿童便器等。根据发育水平提供适当的玩具、图片、图书。
- **儿童空间**：设置相对固定且安全的活动区域，符合婴幼儿特点和发育水平。

### 5.2 日常护理

- **衣着**：合格、舒适、清洁、安全。穿衣/换尿布时给予回应和互动，逐步引导自主穿衣。
- **盥洗**：经常洗澡（养育人全程在场）。借唱儿歌、讲故事等方式示范正确洗手、洗脸、刷牙方法。
- **大小便**：关注排便前的动作和表情，固定排便场所。逐步培养表达方式，2岁后逐渐减少白天用尿布。

### 5.3 推拿保健

学习摩腹、捏脊等常见推拿保健方法，对婴幼儿进行日常推拿保健。

### 5.4 睡眠

| 要点 | 说明 |
|------|------|
| **环境** | 安静、空气新鲜，室温20℃～25℃；白天不过度遮光，夜晚睡后熄灯；卧室不放电视等视频类产品 |
| **时长** | 婴儿期 12～17小时/天，幼儿期 10～14小时/天；夜间睡眠应达8小时以上 |
| **入睡** | 培养自主入睡习惯，敏感识别睡眠信号，及时让其独立入睡；**避免抱睡、摇睡、含乳头睡** |

## 六、伤害预防

### 6.1 加强看护

- **专心看护**：不看手机等电子设备，不从事其他非必要活动。多人同时在场时，明确一人负责照护。
- **近距离看护**：在水中/水边、高处、有动物等情况下，保持伸手可及的距离。
- **看护禁忌**：不让婴幼儿独处，不与其做不安全游戏，不让未成年人看护。
- **行为示范**：养育人遵守安全规则，教会幼儿识别伤害风险，帮助建立安全行为习惯。

### 6.2 营造安全环境

- **清除隐患**：随时排查和清除尖锐物品、可入口鼻耳的小件物品/食物、破损玩具、不安全的运动设备和电器、药物、化学品等。
- **隔离危险**：楼梯和厨房安装护栏/门栏；药物、化学品、热物、刀具、电源、电器放在婴幼儿无法接触到的固定位置；水池、沟渠安装护栏；水桶、水盆、井加盖。
- **使用安全产品**：选择有安全质量认证的适龄玩具和儿童用品，使用儿童安全座椅、家具防护角、窗户锁等。

### 6.3 紧急处置（养育人应主动学习）

- **心肺复苏**：掌握婴幼儿意识、呼吸、心跳的判断方法和心肺复苏技术。
- **常见伤害处置**：学习院前止血、包扎、固定、搬运技术；掌握气道异物梗阻的处置（腹部冲击法、背部叩击法、胸部冲击法）；掌握烧烫伤后用凉水冲洗、浸泡、安全去除伤处衣物、防止创面感染的方法。
- **虐待暴力**：怀疑婴幼儿遭受虐待或暴力时，及时寻求专业部门援助，并向公安机关报告。

## 七、常见健康问题防控及照护

### 7.1 高危儿

早产儿、低出生体重儿、有出生并发症的新生儿等，需及时就诊，在医生指导下进行家庭干预和护理。

### 7.2 营养性疾病

| 疾病 | 预防与处置 |
|------|-----------|
| **缺铁性贫血** | 6月龄起及时添加富含铁的食物；发生贫血按医嘱补充铁剂 |
| **营养不良** | 合理添加辅食，保障能量、蛋白质等营养素；连续2次体重增长不良或营养改善3～6个月后身长仍增长不良者，需专科会诊 |
| **维生素D缺乏性佝偻病** | 发病高峰3～18月龄；出生数日后即开始补维生素D，充分户外活动暴露身体部位；发生佝偻病按医嘱治疗 |

### 7.3 传染病

常见传染病：幼儿急疹、风疹、手足口病、水痘、流感等。

- 及时接种疫苗，保持室内空气流通，注意个人卫生，积极运动锻炼。
- 流行期间不去人多聚集处。
- 患病期间遵医嘱治疗，做好隔离和清洁消毒，注意休息和营养，做好口腔、皮肤护理。

### 7.4 危重症识别（出现以下任一症状立即就诊）

- 精神状态较平时差，进食量明显减少，不能喝水或吃奶
- 抽搐或囟门凸起
- 频繁呕吐
- 呼吸加快（<2月龄超过60次/分、2～12月龄超过50次/分、2～3岁超过40次/分）
- 鼻翼扇动、胸凹陷等呼吸困难，呼吸暂停伴紫绀
- 腹泻水样便持续2～3天，大便带血，小便明显减少或无尿
- 眼窝凹陷或囟门凹陷，皮肤缺乏弹性，哭时泪少
- 脐部脓性分泌物多，脐周皮肤发红和肿胀
- 新生儿皮肤严重黄染（手掌或足底）、皮肤脓疱
- 眼或耳部有脓性分泌物
